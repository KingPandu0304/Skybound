*Skybound*

Skybound is a youth-focused web app created to help people turn coach or teacher feedback into clear goals and steady progress. Users can record feedback, create goals with steps and next actions, choose a Current Aim, plan sessions and habits, review progress, and explore their history, calendar, records and milestones. The app is designed to be friendly and supportive, without leaderboards, public rankings or guilt-based streaks. It is built with vanilla HTML, CSS and JavaScript, with user data stored locally in the browser. Created by AM and ESJ for the TeenTech challenge.
